# Smart Wall Paint Visualizer

**A MEAN Stack web application for virtual room paint visualization**

## Tech Stack
- **Frontend:** Angular 15+, HTML5 Canvas, SCSS
- **Backend:** Node.js, Express.js, RESTful APIs
- **Database:** MongoDB
- **Authentication:** JWT

## Features
- User registration & login
- Upload room images
- Manual wall area selection (brush/polygon tools)
- Apply virtual paint colors
- Save & download designs
- Admin dashboard for color/design management

## Project Structure

├── backend/ # Node.js + Express APIs
├── frontend/ # Angular application
├── docs/ # Documentation
└── public/ # Shared assets
